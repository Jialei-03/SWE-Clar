# Integer lattice explorer

Extend the working Python HTTP service and browser Canvas2D explorer. It already enumerates positive solutions of a*x+b*y=n for coefficient families and draws the raw geometry. Implement family policy filters, normalized coordinate views, interactive comparison and CSV export, and correct handling of overlapping requests and failures.

The local development environment and synthetic fixtures are prepared. Work in `/workspace`; no customer accounts or external deployment are required.
