# Offline optical target measurement

Complete a local image-measurement application used to replay synthetic calibration captures. Preserve its working HTTP service, P2 grayscale-image parser, browser canvas preview, capture upload and SQLite report download. Extend the provisional analysis to extract a target from actual pixels, replay two measurement phases and apply the agreed quality and decision rules. This is an independently reconstructed software task; all fixtures are synthetic calibration patterns.

The local development environment and synthetic fixtures are prepared. Work in `/workspace`; no customer accounts or external deployment are required.
