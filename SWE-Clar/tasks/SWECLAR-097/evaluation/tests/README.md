# Evaluator runtime

Python 3.13, Node 22 and Playwright Chromium are required. SWECLAR_NODE_REQUIRE_ROOT selects the package.json used to resolve Playwright. Leaflet 1.9.4 is bundled with its license. Run the official verifier against SWECLAR_PROJECT_DIR.

Temporary loopback provider and application services use independent users, venues, prices and payment signatures. No actual payment service or personal location is accessed. HTTP receipt verification, concurrent SQLite transactions and browser map geometry are exercised, including a lost confirmation response followed by page reload and retry. Expected map centers permit subpixel projection rounding; selected marker coordinates are checked separately.

One-credit eligibility remains pending source review. Native Apple Pay, real provider identity/settlement and mobile device behavior are excluded. This privileged evaluator directory must not be mounted into the coding-agent workspace.
