Run official_verifier.py with SWECLAR_PROJECT_DIR pointing to an isolated candidate project. Python 3.11+, Node 22, React 18.3.1, esbuild 0.25.0 and Playwright Chromium are required. UI_NODE_MODULES optionally points to preinstalled modules; SWECLAR_NODE_REQUIRE_ROOT points to the Playwright runtime package.json. Tests create a separate synthetic provider, accounts, tone audio and SQLite database; exercise real HTTP, concurrent transactions, persisted state and actual browser media. No original account or paid provider is used. Test artifacts and optional STREAM_QA_OUTPUT stay outside the dataset. This component does not certify DRM, native delivery or security standards.
