# Seven-pane wxWidgets workspace shell

Create the first-stage desktop shell for a larger engineering application. The
delivery must be a C++11 and wxWidgets project that builds with
CMake on the prepared Linux/GCC platform. This stage is intentionally a visual shell: do not
implement project editing, verification, compilation, or other business
operations.

The local development environment and synthetic fixtures are prepared. Work in `/workspace`; no customer accounts or external deployment are required.
