# Native workspace shell

Repair this existing wxWidgets MVC project on the prepared Linux/GCC platform. Build with `cmake -S . -B build && cmake --build build`; launch `xvfb-run -a ./build/workspace_gui --smoke` for an unattended smoke check or run the binary on an X11 display. No business operations or dialogs are required.

This is an independent Linux C++11 adaptation. It does not establish compatibility with the original job’s Visual Studio 2013 environment. The fixed pane identifiers, menu labels and perspective APIs are synthetic contracts; no original screenshot, design file or customer code is provided.

Public native observation helpers collect real wxWidgets objects; protected tests evaluate observations outside the candidate process. If custom perspective naming is requested, use an inline text control named `perspective_name`, with Windows menu actions `Save perspective` and `Default perspective`; these are independent interaction conventions, not original customer API claims.
